# Changelog

## 1.0.0 — 2026-09-24

First public release.

- Sample rate: fixed 44.1 – 192 kHz or Follow apps, applied live and persisted.
- Buffer size (Auto, 64 – 1024 samples) with latency readout.
- Preamps: gain knob with level halo, meter, Inst, Air (Presence / + Drive),
  Auto Gain with result, Clip Safe; 48V and Link.
- Direct monitor Off / Mono / Stereo with per-source levels.
- Live output and input meters.
- Device settings: front-panel brightness and sleep, Auto Gain targets.
- Firmware updates via `scarlett2`, with settings backup and restore.
- Keyboard shortcuts; follows the active Omarchy theme.
